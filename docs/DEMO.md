## 现场演示

1. 按[部署说明](DEPLOYMENT.md)准备TX2、依赖和模型；按[巡检操作](INSPECTION_DEMO.md#运行)配置相机地址、账号及本机RTSP端口。
2. 停止其他控制服务，固定相机，让一个目标保持位置稳定。
3. 启动Demo，打开8772端口页面，确认新画面、人体框和相机状态正常。
4. 点击“扫描并巡检”，展示扫描、去重、访问顺序、居中、变焦、采集及终态。
5. 查看保存预览图和裁图，下载JSON/CSV，明确指出reading为空。
6. 结束后确认停止。首次标定与已有标定缓存的耗时分别报告。
