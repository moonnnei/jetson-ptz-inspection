# 固定机位仪表图像巡检：2026-10-24 冻结版

版本标签：`freeze-2026-10-24`。本版冻结仪表图像采集工程；历史人体演示标签 `v0.5.0-demo` 保留。后续改进使用新提交和新标签，不移动本标签。

## 本版交付

固定相机安装位置和仪表位置后，操作者控制镜头划定扫描范围，系统采集高清视点、建立可缩放的环视预览并提出疑似仪表。候选默认保留，人工排除误检、画框补漏。系统按来源位置粗定位，在有限邻域补拍、调整构图与倍率、自动择优；离开后再次回访核对，去重并保存软件预置位。后续按启发式路线依次访问，保存新的仪表照片、名称、时间与证据，支持单轮或有轮数上限的周期执行。

日常操作入口为“采集看板”，建图和手动云台控制在“建图与设置”：

- 图墙按清单顺序固定排列，与实际路线排序分开；新图逐卡更新。
- 待采或失败时，当前视图保留最近成功图，并明确标明来源轮次和实际拍摄时间；历史失败轮次显示缺失。
- 点击照片查看原始裁剪，支持缩放、拖动、仪表切换、全屏及带名称/时间下载；改名通过卡片铅笔按钮操作。
- 历史独立按场景、上海日期、轮次查询，可比较最多四轮。新建场景保留原全景、清单和历史。
- 实时监看共用单路视频连接，查看看板不会发送云台运动请求。

## 技术与运行边界

| 环节 | 冻结配置 |
| --- | --- |
| 实验设备 | Jetson TX2；海康 DS-2DC2402IW-DE3 S6 |
| 控制服务 | Ubuntu 16.04 / L4T R28.3.1，Python 3.5 标准库 |
| 图像子进程 | Python 2.7、OpenCV 3.3.1 |
| 仪表检测 | 单类 YOLO11n，640 输入、NCNN CPU FP32；仪表权重自备 |
| 视频与采图 | RTSP 最新帧用于监看；停稳后新的高清抓图请求用于正式留档 |
| 控制与规划 | ISAPI 分段绝对位置、限幅离散 P 修正；软件预置位；有界距离最近邻路线 |
| 网页 | 原生 JavaScript；固定版本 OpenSeadragon / Annotorious 与 CSP 补丁随源码提供；缓存版本 `20261024-dashboard2` |
| 持久化 | SQLite、按内容哈希保存的照片、场景档案与完整任务历史 |

图像接收时间不是相机曝光时间。RTSP 硬件解码不代表模型使用 CUDA 或 TensorRT；本版没有 PID、MPC 或大模型控制。环视预览仍有接缝和几何近似，不能当作精确三维地图。

本版汇总此前实际实验，并没有为发布而重跑相机扫描或巡检：

| 已有证据 | 结论与限制 |

| 网页初始化 | 同一实验现场19视点、227次检测，34条观测归为27组；12组有限尝试，15组延后，6项不确定保留 |
| 固定四表回访 | 较早五轮20/20次逐表访问、40次新图身份核对；不同版本记录分别保留 |

| 结果显示与数据保留 | 看板部署时只读核查为15场景、97条历史任务、412张引用照片，文件与内容哈希一致；当时所选场景的末轮计划为3个仪表，不把历史四表实验当作任何当前清单；后续现场实验继续追加保存 |
| 网页检查 | 生产脚本的坐标、卡片更新、裁剪、失败补位、历史、名称保护、CSP与实际查看器API契约检查；不是实际浏览器渲染验收 |

## 可复现入口

电脑需要 Python 3.11 或 3.12；网页检查另需 Node.js。默认审核服务不连接相机：

```bash
git clone https://github.com/moonnnei/jetson-ptz-inspection.git
cd jetson-ptz-inspection
git checkout freeze-2026-10-24
python scripts/test_local.py
node scripts/test_results_model.js
node scripts/test_results_ui.js
node scripts/test_scene_navigation_ui.js
node scripts/test_workbench_ui.js
python scripts/check_release.py --verify-manifest
python src/inspection_console/server.py --host 127.0.0.1 --port 8775
```

访问 `http://127.0.0.1:8775/`。新克隆没有私有照片或场景数据，需按[审核服务](REVIEW_CONSOLE.md)导入自己的原图与清单。接入真实设备前按[软件预置位部署](SOFTWARE_PRESET_PATROL.md)准备兼容的仪表模型、NCNN程序、相机连接和允许范围；服务本身不自动扫描或启用周期。历史通用 YOLO26n 权重随仓库提供，不能代替仪表检测模型。

## 冻结与恢复约定

公开源码ZIP与本标签中的文件一致，并提供SHA-256校验文件。公开文件范围以 `FILE_MANIFEST.json` 为准；Git文本使用LF，已验证模型及指定配套文件保持原字节。板端实际部署文件另外按各自哈希保留，文本换行规范化不用于覆盖在线服务。

现场SQLite一致性快照、图像、实际仪表模型与运行程序、本地训练检查点和实验原始资料只放入本人的私有恢复档案，不放入公开ZIP、Git历史或Release附件。凭据不写入归档脚本、Git远程地址或命令行。

运行中的系统允许在线取得事务一致的SQL快照和该快照引用的不可变照片。快照可能包含尚未完成的任务，不能据此宣称整轮成功；后续产生的数据不会回填到该快照。恢复时先使用新目录和默认审核模式，保持周期暂停，再核对清单与现场条件。

回退源码与恢复数据库分开执行。只切换源码时保留现行数据；需要迁移私有档案时先恢复到新目录，校验SQL、照片哈希、软件预置位和机位条件。禁止用旧数据库覆盖后来产生的现场记录。

## 后续工作

本版未接入仪表数值读取，`reading=null`；超分保留为独立实验。远景漏检、相似邻表、光照与遮挡、机械限位导致的偏心、陌生场景发现率、跨天和长期巡检仍需独立验证。网页自动视觉验收受当前浏览器自动化网址校验限制，不能将脚本检查表述为实际浏览器操作验收。冻结本版不代表这些问题已解决。
