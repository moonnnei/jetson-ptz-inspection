# 仪表采集结果

工作台上方有“采集看板”和“建图与设置”两个入口。已有登记仪表时首次进入看板；所选入口会在本机浏览器记住。没有登记仪表时引导到建图。此模块不启用超分或数值读数。

看板以仪表照片为主，旁边提供可折叠的实时监看；窄屏时监看排列在图墙上方。扫描、补框和云台手动控制位于“建图与设置”，看板的实时图仅供观察，点击不会触发云台移动。两种空间共用同一个实时视频元素，不复制视频连接。

“采集操作与周期设置”折叠保留单轮采集与周期配置。切换空间或查看照片本身不会触发采集、启用周期或修改仪表位置。

## 当前轮次

每块仪表显示名称、固定编号、裁剪图、真实拍摄时间和图像来源轮次。图墙按仪表清单顺序排列，独立于每轮的实际行走路线；同一批计划目标不会因为路线改变而交换位置。本轮有通过检查的新图就更新该卡；尚未采集或本轮未成功时，沿用上一轮最近可用的成功图，并明确标注旧图来源和本轮状态。完全没有历史时显示等待首次采集。

刷新只替换内容发生变化的卡片，其他图片、焦点和滚动位置保持。进度条包含本轮已确认的新图与待整轮确认的进度图，文字分别列出两者，不把旧图算入进度。

沿用旧图只是显示规则，不生成新采集记录、不重写拍摄时间，也不计入本轮成功数。新周期批次尚未开始第一轮时，不把上一批次最后一轮当成本轮成功。

逐表拍完后提供“待整轮完成确认”的进度图，正式结果仍由原有调度器在整轮流程返回并完成停止检查后发布。预览与正式 results 分开保存；整轮失败或停止未确认时，预览不会被提升为已验收结果。预览发布异常不改变采集、限位或 STOP 策略。

## 历史结果

“历史场景”下拉列表可直接找回旧场景的采集轮次；它独立于当前建图/巡检场景，不驱动相机。工作台“场景档案”还可切换旧全景与清单，并记住刷新前的选择。详见[场景档案与数据保留](SCENE_ARCHIVE.md)。

按上海时间的日期及真实采集轮次筛选。历史轮次中失败或未访问的仪表显示该轮的缺失状态，不用另一轮的图片填补。单表建档任务不计为第1、2、3轮；旧的有限试采轮次有明确“试采”标签。周期批次信息仍保存在原始记录中。

“上一轮／下一轮”在筛选后的轮次中切换。“跨轮对比”以仪表为行、轮次为列，显示选中轮次及其之前最多三轮；继续切换轮次可浏览更早或更晚的照片。缺失照片显示空缺，不沿用其他轮次的图。后台产生新轮次时保持用户正在看的历史轮次。

页面首次打开会同步完整归档，历史页可手动重新读取；近期窗口之外的已登记图像也可以访问。页面持续打开时保留已看到的完成轮次，避免近期窗口滚动造成轮号重置。下载的清单及原始记录继续保留。新名字用于展示相同内部编号，历史照片时间不变。

## 裁剪与名称

- 只使用与本张照片配对的 bbox；不会拿旧图的坐标直接裁剪一张新图。旧照片在浏览器按配对坐标裁剪，后续采集会同时登记原有图像工作器已经生成的裁剪文件及其源图哈希。
- 缺少可靠裁剪框时提示查看原图，不把整幅环境图标成仪表裁剪图。
- 图墙使用最长边不超过640像素的缩略画布，并在接近可见区域时载入；大图查看器保留原始裁剪像素，不合成细节。缩略画布更轻，但旧记录没有独立裁剪文件时仍需读取完整源照片。
- 点击照片打开大图：滚轮缩放、按住拖动，按钮或左右键切换仪表，支持适应窗口、原始大小、全屏和 Esc 关闭。下载入口和完整原图链接集中在此处。PNG 下载附名称、编号、真实拍摄时间和来源轮次。小分辨率、反光和失焦仍受原始成像限制。
- 查看器保留打开时的图像快照。后台收到同一仪表的新图会提示“已有新图”，由用户点击更新，避免正在核对时突然换图。跨场景后不会把另一场景的新图替换进来。
- 当前轮次卡片标题右侧的铅笔按钮可修改名称；名称表单只在操作时打开。仅改显示名称，不修改启用状态、仪表编号、位置或回访证据。为避免改变正在运行的路线校验，需在采集/运动结束且周期任务暂停时改名。
