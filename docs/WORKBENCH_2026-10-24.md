# 巡检工作台交互修订

本页记录 2026-10-24 的交互修订和实测边界。目标仍是固定机位、固定仪表的发现、建档和留图；不接入数值读数或超分。

后续新增[仪表结果展示](RESULT_GALLERY.md)：当前轮次逐表更新，未采目标显示上一轮结果并标明来源；历史按日期/轮次查看，支持原像素裁剪图下载和名称保存。超分仍未接入。

## 使用流程

1. 通过方向按钮、变焦或点击当前实时画面调整视线，分别把扫描区域的两个对角位置置于画面中央并记录。需要重选时清空角点。
2. 开始扫描。进度条同时显示采图、检测阶段的实际计数、建图状态和用时。可以停止，或停止并返回范围设置，已有照片和场景继续保留。
3. 扫描完成后显示全景和疑似仪表。后台合并跨视点的重复观测，每组只显示一个代表框和一条列表项。框上编号与列表一致。点击缩略图、编号或全景上的框，自动定位并用橙色粗框标出，同时显示原图裁剪。勾选列表也会定位，勾选本身只用于批量排除；所有未排除目标默认保留。显示已排除项后可以恢复。
4. 漏检使用“画框补漏”：先缩放至合适大小，点击按钮，按住左键拖出覆盖表盘的矩形，松开保存。独立指针层显示实时矩形并暂停大图平移，不与组件内部拖动竞争；触屏使用同一指针流程。按 Esc、取消或指针中断不会保存。后台自动选取覆盖该框的高清来源，不再弹出逐张来源确认。框过大、跨越无覆盖区域或保存失败会提示，恢复浏览后可重试，无需刷新。
5. 完成排除和补漏后，开始自动建档。系统继续进行目标复检、身份核对和独立回访；通过后才可以单轮或周期采集。

箭头表示镜头视线的方向。点击回中使用当前画面位置、倍率和版本化焦距估计；超出机械范围时显示边界提示。它是近似定位，不是精密的点击标定。自动任务运行时先停止再手动接管，保证一个运动所有者。

## 已解决的具体问题

| 反馈 | 修订 |
| --- | --- |
| 点击和上下箭头方向反了 | 实拍图对比核对坐标，修正垂直轴符号；前后端统一到直立画面坐标，黑边点击不触发运动 |
| 每次移动视频都会断开 | 删除移动结束后的 MJPEG 主动重连；状态查询短暂失败时保留健康的视频连接，并显示等待状态 |
| 必须等移动结束再发指令 | 独立单工作线程和单个可替换意图；旧动作取消、STOP 确认后执行最新指令，中间意图不积压 |
| 操作失败后需要刷新 | 请求设置超时，错误后释放界面状态；提供停止、返回和重新选择范围，暂停队列不会永久挡住新扫描 |
| 扫描没有反馈 | 显示视点采集数、处理数、阶段和实际用时；完成扫描后停在审核阶段 |
| 同表多次审核，部分勾选无法排除 | 后台使用同一套跨视点分组来驱动显示、排除和建档；排除事务作用于整组，不受浏览器过滤或候选状态影响 |
| 小范围扫描也很慢 | 按视场覆盖选择视点，小范围可只拍一张；采图与检测重叠，NCNN 进程在同一批内复用 |

分组采用角度框重叠、同帧约束和完整链接匹配，避免仅靠相邻中心把多个表连成一组。它是发现阶段的假设归组，不冒充已经通过外观核对的正式仪表身份。历史观测和排除记录保留。恢复操作恢复为待处理，不会伪造通过的预置位。

## 开源组件

- 实际本地接入 [OpenSeadragon 6.1.1](https://github.com/openseadragon/openseadragon) 和 [Annotorious OpenSeadragon 3.9.5](https://github.com/annotorious/annotorious)，负责大图缩放、平移、坐标映射及框的显示与点击。补漏使用本工程的独立指针层，编号及定位框使用 OpenSeadragon 图像坐标覆盖层；库内置画框保持关闭。固定构建产物、CSS、BSD-3-Clause 许可证、npm 完整性值和逐文件哈希随工程分发；浏览器无需访问 CDN。
- [Frigate Live View](https://docs.frigate.video/usage/live/) 的点击回中、[ZoneMinder 海康适配器](https://github.com/ZoneMinder/zoneminder/blob/master/scripts/ZoneMinder/lib/ZoneMinder/Control/HikVision.pm) 的接口语义作为参考，未复制其控制源码。保留本工程的 ISAPI 适配、互斥和限位。
- [go2rtc](https://github.com/AlexxIT/go2rtc) 已调研但未接入。本轮保持已有 RTSP/MJPEG 链路，先移除网页自身造成的重连。

## 实测结果及限制

2026-10-24 后续兼容修订：实际浏览器报告 Pixi 的 `unsafe-eval` 错误。对固定 Annotorious UMD 中内嵌的 Pixi 7.4.3 应用官方 `@pixi/unsafe-eval` 7.4.3 静态 uniform 同步实现，未放宽网页 CSP。修订脚本与原始构建哈希保留在工程中，并为组件初始化失败增加清理和重试，避免影响实时监看与控制。对真实构建产物在禁止动态代码生成的 Node VM 中复现旧错误，修订后初始化和 uniform 同步通过；这项运行回归仍不代替浏览器实际拖框验收。

随后修正 `viewer.viewport.stop is not a function`：此版本没有该方法。进入补框时改用 `getCenter(true)`、`getZoom(true)` 读取当前显示位置，再用立即执行的 `zoomTo`、`panTo` 固定视图。原测试替身错误地提供了 `stop()`，未能暴露兼容问题；新增加载实际 6.1.1 构建的 Viewport/Spring 回归，并强制测试替身的方法与真实原型一致。相关检查纳入 CI。

- TX2 控制台 252 项检查通过；PC 标准库整套 489 项，488 通过、1 个平台跳过。
- 在旧动作未完成时发送反向指令：确认响应约 0.243 秒，替换后的动作约 0.636 秒完成。停止请求约 0.363 秒完成。响应确认、到位时间和视频端到端延迟是不同指标。
- 同一条 HTTP 视频连接跨过点击回中、方向替换和停止，连续收到 50 帧，未发生连接错误。不能由此推断长期运行已验收。
- 点击点通过实拍前后图 ORB/RANSAC 配准核对：横向残差约 27.8 px，纵向约 -44.2 px，图像为 2560×1440；方向正确，尚存在近似焦距与运动成像误差。
- 一次 4°×3° 小范围试验：1 个视点、11 次检测，约 18.58 秒结束并进入审核阶段。之前同尺寸小范围试验为 4 个视点、约 70.07 秒；两次朝向和画面内容不同，不是严格同图基准，也不代表全范围扫描都在 19 秒内完成。
- 真实历史库的隔离副本：16 条观测归为 8 组，一次排除覆盖某组全部 3 条观测，恢复通过；在线数据库未改动。正式仪表身份仍需要建档复检。
- 网页事件和坐标单元检查通过。补框回归加载真实工作台及全景适配代码，覆盖列表/框的编号联动、缩放平移坐标换算、反向与越界拖动、取消、场景切换、保存失败恢复以及重复松键只提交一次。本轮浏览器自动化接口仍超时，未宣称完成浏览器实际渲染、滚轮和拖框验收。需要在浏览器刷新一次载入新版进行交互复核。

本轮没有完成端到端视频延迟测量、陌生场景覆盖率验收或长期稳定性验收。多行总览沿用按俯仰分行的近似投影，不是精密三维地图。前端组件改善操作，不会消除模型漏检或拼接误差。
