## 运行边界

| 模块 | 部署位置 | 输入 / 输出 | 当前设备行为 |
| --- | --- | --- | --- |
| RTSP 与仪表检测 | TX2 | 视频 → 最新帧、检测框与序号 | 只读视频，不主动跟随 |
| 有限扫描 CLI | TX2 | 新计划 → 高清来源图、姿态与哈希 | 显式执行后有界运动 |
| 环视预览与候选发现 | PC | 原图 → 投影/配准预览与来源候选 | 不连接相机 |
| 默认审核控制台 | PC 或 TX2 | 来源/候选 → 档案与补漏框 | `NoHardware`，不驱动相机 |
| 自动建档适配器 | 显式配置的 TX2 | 候选或补漏 → 新参考、独立回访与身份去重 | 有界定位、变焦和抓图 |
| 软件预置位与调度 | 同一 TX2 控制台 | 有效档案 → 单轮或固定延迟周期图像 | 同相机共享锁串行；本次周期关闭 |
| 历史人体 Demo / 跟随 | TX2 独立入口 | 人体观测 → 运动演示 | 不与当前仪表巡检并发 |

PC 初始化工具通过文件清单与校验导入衔接；上电自动环视建图尚未统一编排。启用自动建档的场景导入可请求自动候选注册。旧地图不会因服务更新而把全部历史待审核候选立即执行。

## 三种位置

1. **来源姿态**：扫描原图拍摄时的 pan/tilt/zoom，可能同时包含多个目标。
2. **估计与搜索位置**：由来源框和估计焦距计算，有限邻域与新图外观链用于修正，尚非标定的几何投影。
3. **采集位置**：经过新图、构图与独立回访验证的软件预置位。机械受限时允许偏心，保存残差及图像边界结果。

不能仅复制来源姿态就宣称采集位置已经有效。当前固定四表的采集位置已实测，换安装或移动目标后需要重建。

## 图像与坐标

- 图像通过 SHA-256 标识，保存方向、尺寸和来源姿态；候选框为来源图中的 `[x1,y1,x2,y2]` 像素坐标。
- 旋转时图像与框同步处理，原始字节及哈希保留。模型 ROI 推理不再次旋转已经归一化的图像。
- 局部平面总览可有单应矩阵；柱面环视使用非线性映射，不伪造平面单应或精确标定。
- 当前扫描使用水平 0～350°，本轮局部建档限定俯仰 0～25.5°、倍率 1～2；不同型号需核对能力。
- 实时预览是 RTSP 最新帧；巡检照片来自停稳后的新高清抓图请求。接收时间不等于相机曝光时间。

## 建档、来源和去重

`AnnotationService` 持久保存队列，最多一项运动任务运行。自动候选需两次新图 NCNN 语义复检；人工补框保留 `human_labeled` 来源。自动结果不写成“人工确认”。方位筛选后仍需局部外观和区域重叠证据才能归并重复身份，歧义保留为不确定。

预置位由采集位置、参考图/框、来源和独立回访证明组成。核心证明固定在仪表档案中，最近任务窗口裁剪不会使其失效。清单新增目标时，只有像素来源未变化的旧预置位可重绑，不伪造新实机验证。

## 存储与调度

SQLite 保存版本化清单及追加审计，图像内容寻址。写入核对整数修订号并在单一事务完成；旧网页请求返回冲突。编号不复用，重复身份保留原图和别名记录。

单轮入口与周期启用分开。固定延迟从上一轮结束后计算，防止任务重叠；失败、停止异常或重启使周期暂停。全局停止也暂停建档队列，重启不重放已开始的尝试。周期与建档之间共享相机控制资源。

`/api/state` 可包含显示用派生坐标；导出保留原始存储字段。默认监听 loopback，局域网部署显式允许 Host；控制令牌防跨站请求，不代替登录。凭据通过标准输入进入内存，设备数据不进入公开文件清单。

## 当前方法

建档采用分段绝对定位、每步更新新外观参考、限幅 P 修正、逐级变焦及自动择优。后续巡检用软件预置位和最近邻启发式路线，两张新图复核后留档。它不是 PID，也不保证全局最短路线。模型推理为 NCNN CPU FP32，RTSP 硬解单独配置。
