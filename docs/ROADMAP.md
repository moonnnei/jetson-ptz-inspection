## 下一阶段：完成真实仪表闭环

1. 用不同方向/高度的真实仪表建立清单，人工确认和补漏；记录每块表的参考图、搜索位置与最终采集位置。
2. 完成受控的单轮访问：粗定位 → 最新图像复核 → P 视觉微调 → 变焦/聚焦检查 → 高清新图留存。身份有歧义时拒绝自动确认。
3. 多轮实测发现率、回访成功率、中心误差、有效图像比例、单表/整轮耗时和失败原因。保存图重放不能计为新采集。
4. 接入经过检查的硬件周期执行。周期由操作者设置，上一轮未结束时不启动重叠任务。
5. 对接读数模型和最终网页结果；整理可复现实验、论文及演示材料。

## 场景变化与后续研究

固定机位指相机安装位置固定，云台可以转动和变焦。安装或仪表位置变化后，旧采集位置不能直接复用；需重新定位、重新教学或建图。无约束移动平台、强反光、遮挡、外观相同的相邻仪表及远距离细节不足需另行验证。

当前使用绝对位置和离散 P 视觉微调，未实现通用 PTZ 几何标定、PID、模型预测控制或运动预测。人员连续跟随保留为独立实验，仍有明显滞后。
