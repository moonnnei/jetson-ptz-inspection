# 开发路线与验收边界

当前状态：v0.5.0-demo，工程实验阶段。已经实现的代码、单次实机结果和仍未验证的能力分别记录，不能互相替代。

| 阶段 | 目标 | 状态与验收依据 |
| --- | --- | --- |
| 环境与推理 | 旧TX2运行已转换模型，输出可用检测结果 | 已部署；NCNN CPU FP32，非TensorRT GPU推理 |
| 采集链 | RTSP硬解、最新帧、同帧预览和检测 | 已实现并在实机运行 |
| 固定单目标巡检 | 扫描、去重、定位、放大、居中、留图 | 已有一次新修订完整实机成功；尚无重复成功率 |
| 重复及多目标 | 两个及以上固定目标依次采集 | 状态机有离线覆盖，真实多目标未验收 |
| 完整场景发现 | 覆盖规划、重叠区域去重、完成判据和漏检评估 | 当前仅起始方向−8°、0°、+8°，尚未实现全场景覆盖 |
| 实际仪表成像 | 仪表检测、高分辨率、清晰度和反光处理 | 等待仪表模型与实际面板，当前保存960×540检测预览 |
| 读数与业务 | 模型接口、单位、读数质量、记录和上传 | 待接入；当前reading=null，不生成假读数 |
| 平台位置变化 | 平台暂停后重新发现和标定 | 需独立设计与验证，旧缓存不适用于变化场景 |

下一轮实机优先重复固定单目标实验，记录成功率、失败原因、中心误差和整轮耗时分布；然后验证两个固定目标的去重及依次采集。新增试验须重新确认现场准备，不能因自动任务唤醒直接转动相机。

人员移动跟随是独立实验方向，旧版本仍存在明显滞后。当前定点巡检使用绝对位置与离散P视觉伺服，未实现PID、模型预测控制、目标运动预测或通用云台几何标定。
