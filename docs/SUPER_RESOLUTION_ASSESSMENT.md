# 超分辨率对照：本轮不接入巡检主流程

本轮在 PC 上比较同一 ROI 的原始输入、4 倍双三次放大和 Real-ESRGAN 4 倍超分。四个已有现场正样本在普通 ROI 输入下已经全部检出，超分没有新增正确检出，处理时间增加。因此保持原图裁剪与光学成像作为当前主流程。

## 可复现条件

| 项目 | 配置 |
| --- | --- |
| 检测模型 | 已训练 YOLO11n 单类 `meter`，检查点 SHA256 `e6bf75f5aa415b86d62e06497b9adfabefd815a7699df3ff24a22de5fef688f8` |
| 检测输入与阈值 | 所有分支固定 640、置信度 0.25、NMS IoU 0.45 |
| 正确匹配 | 与已有来源标注框 IoU ≥ 0.5；一个真值最多匹配一次 |
| 区域 | 相同的标注框加 25% 边缘；三种分支不改变搜索区域 |
| 超分模型 | `realesr-general-x4v3`，32 层紧凑 SRVGG，单权重、去噪强度 1 |
| 超分设备 | PC CPU FP32，PyTorch 四线程 |
| 重复 | 预热后各三次，记录中位耗时 |

Real-ESRGAN 权重来自[官方发布](https://github.com/xinntao/Real-ESRGAN/releases/tag/v0.2.5.0)，SHA256 为 `8dc7edb9ac80ccdc30c3a5dca6616509367f05fbc184ad95b731f05bece96292`。结构源码固定到[提交 a4abfb2](https://github.com/xinntao/Real-ESRGAN/tree/a4abfb2979a7bbff3f69f58f58ae324608821e27)，保留 BSD-3-Clause 许可。实验仅去掉结构注册器依赖，未改动网络计算结构。上游[推理入口](https://github.com/xinntao/Real-ESRGAN/blob/a4abfb2979a7bbff3f69f58f58ae324608821e27/inference_realesrgan.py)列出了该通用图像模型的配置。

检测在 PC 参考实现上进行，不是 TX2 实测推理时间；模型加载、文件读写和相机运动不计入下表。

可复用的独立 PC 比较入口和输入清单格式见[模型工具说明](../tools/model_export/README.md)。该脚本使用同一固定检测器和上游哈希，现场图片及权重由使用者自行提供；下方数值仍来自本轮原始实验记录，不由后续小型复现检查替换。

## 结果

| 样本组 | 原始同 ROI | 双三次 4× | Real-ESRGAN 4× |
| --- | --- | --- | --- |
| 4 个现场正样本 | TP 4、FN 0、FP 0 | TP 4、FN 0、FP 0 | TP 4、FN 0、FP 0 |
| 同四图缩小一半的合成样本 | TP 4、FN 0、FP 0 | TP 4、FN 0、FP 0 | TP 4、FN 0、FP 0 |
| 4 个背景裁剪块 | FP 0 | FP 0 | FP 0 |
| 现场正样本的中位单图总耗时 | 147.6 ms | 152.8 ms | 1324.6 ms |

原始 ROI 进入检测器时同样经过固定输入尺寸缩放，不能把“只裁剪”称为完全不放大。双三次和超分分支都生成四倍图，再进入同一检测器，比较的是相同区域内的增强方式。

四个现场样本来自同一桌面场景，四个缩小样本与其相关；背景块也不是大规模独立负样本。此次结果不能证明超分对所有远景无效，更不能据此宣称通用 100% 准确率。当前普通 ROI 已达到这组样本的检出上限，尚无证据支持为主流程增加超分成本。

## 对远景问题的含义

2560 像素宽的整图缩到 640 时，173 像素宽的表盘只剩约 43 像素；约 97 像素宽的表盘只剩约 24 像素。保留高清来源、重叠分块或对候选 ROI 单独推理，可以提高表盘在检测输入里的占比，不需要先合成细节。

本轮另在 TX2 对四张已保存的近景表盘裁剪运行原生 NCNN，4/4 检出；这是接口与已知裁剪正样本检查，不是自动发现准确率。较宽上下文中的若干新图裁剪曾未检出，说明区域尺度和成像仍需受控评估。

超分以后仍可作为可选实验分支：对更小、失焦或反光等真实难例扩大标注样本，固定区域和检测阈值，比较新增正确检出、误检和总成本。不同云台位置的邻域图默认用于覆盖与择优，不自动当作已经配准的多帧超分输入。原图始终保留，增强图不替代原始证据。
