# 文档导航

[返回项目首页](../README.md) · [English overview](../README.en.md) · [源码导航](../src/README.md) · [模型说明](../models/README.md)

本目录记录固定机位仪表图像采集系统及历史人体运动 Demo 的设计、部署、接口和实验依据。当前已把扫描、高清图检测、环视预览和有限自动建档接入 TX2 本地网页流程，人工用于补画漏检框；数值读数不在本阶段。历史结果须连同对应版本、运行条件和失败记录阅读。

## 当前开发版

- [2026-10-24冻结版本](FROZEN_BASELINE_2026-10-24.md)：交付范围、看板、复现、已有证据、公开/私有文件及恢复约定。

0. [工作台交互修订与实测](WORKBENCH_2026-10-24.md)：持续视频、最新手动指令优先、范围扫描进度、停止返回、后台归组及全景排除/补漏。
0. [仪表采集看板](RESULT_GALLERY.md)：固定图墙、大图缩放拖动、旧图保真补位、按轮对比、裁剪下载和铅笔改名。
0. [场景档案与数据保留](SCENE_ARCHIVE.md)：找回旧全景与清单、跨场景查历史、刷新记住选择及新建不覆盖检查。

1. [TX2 本地场景初始化](SCENE_INITIALIZATION.md)：单命令启动、网页扫描、板端检测与建图、自动建档、补漏、基本图像质量检查及中断恢复。
2. [标注驱动自动建档](AUTOMATIC_REGISTRATION.md)：先拍新图、有限搜索、构图、独立回访、模型复检与去重。
3. [软件预置位巡检](SOFTWARE_PRESET_PATROL.md)：部署、单轮/周期语义、上一阶段五轮实测与迁移回退。
4. [超分对照](SUPER_RESOLUTION_ASSESSMENT.md)：原图、双三次、Real-ESRGAN 的同 ROI 比较；超分保留为后续实验，当前不接入。
5. [有限轮次与执行统计](BOUNDED_PERIODIC.md)：TX2 原生批次上限、失败/取消/重启暂停、单轮耗时及质量补拍统计。

上一阶段固定四表五轮 20/20 次回访通过。本轮同一现场的新初始化真实采集 19 个视点，执行 227 次原生检测，并完成 12 个候选组的有限建档尝试。跨倍率重复已用新参考自动归并，新清单四表完成三轮有限周期、12/12 次采集；模糊拒绝与补拍、真实重启和工程检查见[2026-10-24 复验](INITIALIZATION_VALIDATION_2026-10-24.md)。34 条观测不能当作 34 块仪表，6 个不确定项和 15 个延后组保留。三表偏心、一表遮挡，未知环境准确率与长期周期尚未验收。

## 历史设计与实验阅读顺序

1. 阅读[项目方案](项目方案.md)，了解最终仪表应用与现有原型的关系。
2. 阅读[巡检设计与操作](INSPECTION_DEMO.md)，了解扫描、去重、访问规划、居中和变焦流程。
3. 按[部署实战文章](TX2_YOLO_PTZ_TUTORIAL.md)分步复现环境记录、NCNN 构建、单图推理、RTSP 和 ISAPI 联调；[部署手册](DEPLOYMENT.md)提供运行参数与排错细节。
4. 对照[接口与坐标约定](INSPECTION_DEMO_INTERFACES.md)查看帧、位置、状态和导出字段。
5. 阅读[历史人体实机复验](INSPECTION_DEMO_VALIDATION_2026-10-15.md)和[路线图](ROADMAP.md)，区分已有证据与待验收能力。
