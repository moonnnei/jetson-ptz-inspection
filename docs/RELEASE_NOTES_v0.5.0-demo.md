## Jetson PTZ Inspection v0.5.0-demo

一个基于Jetson TX2、YOLO26n NCNN和海康DS-2DC2402IW-DE3 S6的视觉巡检实验工程。

### 本版内容

- RTSP持续采集与硬件解码，NCNN CPU FP32检测。
- 使用固定人体替代仪表，完成有限扫描、重复观测确认、位置去重和近邻访问规划。
- ISAPI绝对粗定位、按倍率标定的P视觉居中、光学变焦及同帧图像保存。
- JSON/CSV记录、异常状态、心跳取消和STOP失败处理。
- 中英文README、部署及接口文档、实机报告、AGPL-3.0与第三方声明、贡献说明和离线CI。
