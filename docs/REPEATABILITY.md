首次四表回访在 97.773 秒内完成，但单次成功无法给出重复成功率。本模块为已建档的固定场景准备两轮或三轮验证，用相同参考、路线和拍摄姿态重复采集。

2026-10-22，代码已部署到 TX2，PC 与板端完整控制台各 143 项检查通过，其中新增重复回访检查 10 项。首次三轮实测在第一轮因 M0007 配准未通过而结束整组，第二、第三轮未执行。已有的单轮成功记录仍单独保留，不计入本组三轮结果。

在 TX2 OpenCV 3.3.1 上对同一对保存图做离线诊断，围绕参考框按既有位移比例取局部区域、保持原匹配阈值不变，得到 50 个有效匹配点，相关分数 0.819，盘面内区分数 0.819；将盘面抹去的合成负例仍被拒绝。这支持后续减少背景参与的方向，但只有一对现场图与一个合成负例，尚未验证相似仪表排歧义、遮挡或更多场景。

这次初步局部诊断没有修改当时的运行代码、改变原图接受状态或重新启动运动。原 M0007 结果继续保持未通过；该组不能给出三轮稳定性通过的结论。

后续 2026-10-23 已部署[固定机位局部匹配修订](FIXED_POSE_REVISIT.md)，在保存图片上通过 7 对回放及 5 个构造反例检查，再执行下面的新实机试验。离线验证和新试验都不能更改首次试验的历史结论。

局部裁剪同时改变了特征参与区域和提取尺度，不能仅凭这一对图将改善全部归因于背景变化，也不能据此宣称性能提升。后续需要加入相似盘面、错误机位、遮挡和无目标样本，检验误接受风险。

## 执行规则

- 计划最多三轮，绑定同一清单版本、来源照片、目标、范围和起点；以完整计划指纹确认一次执行。
- 每轮沿原自动路线逐表采集，每表最多两次新图请求，正常结束返回起点并确认停止。轮间等待 3 秒。
- 任一轮未完整成功、停止未确认、通信异常、清单改变或取消，结束整组；不继续下一轮，也不自动尝试恢复失败现场。
- 每轮独立保存目录、请求时间、帧信息与图像哈希。组记录绑定每轮记录的哈希，检查跨轮接收时间顺序，防止把同一份结果重复计数。
- 同一共享运动锁覆盖整组。每轮原有预算监视继续生效，整组另有有限时间上限；不是周期调度器。

四表原单轮预算为 240 秒。三轮加轮间等待和收尾余量的上限为 **736 秒**；这不是实测用时。整组预算变化、目标或范围变化时必须重新生成计划。

## 统计口径

每次访问新增明确的开始/结束事件和访问耗时。统计包括计划轮次、实际轮次、完整成功轮次、每表实际尝试次数、成功次数、整轮与逐表耗时；计划与实际尝试次数之差对应未执行次数。失败和未执行的目标保留在分母说明中，不只汇总成功照片。

盘心坐标先除以图像宽、高，再减去 0.5。`mean_center_error` 表示平均偏心；`center_error_population_std` 表示同一固定机位下多次回访的图像位置波动。样本少于两次时不计算波动标准差。稳定地偏在画面一侧，仍不算精准居中；图像位置波动也不是编码器精度的标定结果。

匹配通过表示与参考外观相符，不证明读数可用或身份在所有相似仪表间绝无歧义。当前相机允许偏心成像，部分仪表有遮挡；清晰度与读数质量需另行验收。

## 使用

先只读准备，密码交互输入，不放到参数里：

```bash
python3 scripts/capture_meter_series.py \
  --console-root /path/to/review-console --camera http://CAMERA_IP \
  --user YOUR_CAMERA_USER --map YOUR_MAP_ID --rounds 3 \
  --plan-out var/series-plan-new.json
```

核对计划与当前现场后显式执行：

```bash
python3 scripts/capture_meter_series.py \
  --console-root /path/to/review-console --camera http://CAMERA_IP \
  --user YOUR_CAMERA_USER --map YOUR_MAP_ID --rounds 3 \
  --execute --plan var/series-plan-new.json \
  --acknowledge-plan SAVED_PLAN_FINGERPRINT --output var/capture-series-new
```

输出目录必须全新。完成后可以只读汇总，也可以一次性导入所有实际执行轮次：

```bash
python3 scripts/report_capture_series.py var/capture-series-new \
  --output var/series-statistics-new.json
python3 scripts/import_capture_series.py --data /path/to/review-console/var/inspection-console \
  --directory var/capture-series-new --revision ORIGINAL_PLAN_REVISION
```

导入只增加任务和审核记录，在同一次版本变更中提交全部轮次，保留地图、候选、仪表与旧任务。网页显示轮次及整组摘要；机位不自动升级为已验收，读数仍为空，周期仍关闭。导入后旧计划版本失效，下一次执行需重新准备。

## 后续成像调整

已有四表采集位置中三块的俯仰为 0°，处于机械边界。完成当前固定条件下的重复验证后，再调整安装高度或仪表位置，重新获取合适画面、参考照片和采集位置，验证 P 视觉居中与有效图像质量。几何布局变化后的新结果应单独记录，不能与原固定条件的重复性统计混合。
